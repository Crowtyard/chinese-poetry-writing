用途：理解「物证+关系」如何落地。**禁止当模板抄结构**——每条只配一句「为什么成立」，

## 样本（诗 + 可学点）

《晚妆》人走楼灯灭，回头看一程。千窗次第暗，独亮最高层。
→ 空间逐层熄灭收束到独亮一格；观察视角在场。

《旧信》拆开旧信折痕长，胶带斜斜贴过行。盖到半行没盖住，半行字露胶带旁。
→ 补救动作制造新缺口；斜贴错位=不可替换物证；「盖到半行没盖住」白而不俗（用户原话可接受）。

《江雪》岸上雪加雪，江中波化波。白堆两岸厚，只有黑水多。
→ 有功能重复+静态度量反差。

《江雪》雪落封山后，江心不肯收。千山尽作白，只剩一江流。
→ 收束落在一江流（物态合拢=ENDING_RESOLUTION）。

《空杯》杯中茶已尽，杯底渍成圈。深浅两圈间，水都各自完。
→ 渍圈携带时间分层；停在物。

《旧友》旧忌他还记，新香他不尝。满桌都点齐，留下半桌凉。
→ 满/凉对照，物证在场（点齐的香 vs 不尝的人）。

《山雨》远山先变暗，暗往这边迁。山背雨声近，人停半岭间。
→ 视觉先退、听觉逼近的时间差；「人停」是结果不是解释。

《关灯》关灯之后静，静里有微声。冰柜声先起，墙钟随后鸣。
→ 遮住的东西逐层显现（SEQUENTIAL_REVELATION 干净样本）。

《高铁离乡》灯亮窗成镜，家山面上行。千峰流欲尽，镜里影分明。
→ 一个动作改变一物状态（灯亮→窗成镜），动态链全程在物上。

《秋江》斜阳铺水面，桨落碎金光。桨起光还满，归舟趁晚凉。
→ 动作与光的状态往返两次（碎/合），收尾=链完成+时间推移。

《秋江》叶叶随流去，涡心片叶留。回流带叶转，从此顺波游。
→ 运动链完成于重新顺流（滞留是暂时的）。

《医院走廊》半夜灯同昼，天明灯照常。窗前一线晓，此外尽灯光。
→ 灯无晨暮 vs 窗外一线晓；**无状态变化仍获认可**（动态非必需反例）。

《晾衣》收衣天欲晚，衫上留新斑。早晾原无点，白天谁点斑。
→ 时间差物证（斑从无到有），问句打开缺口不解释。

《晾衣》洗罢一绳晾，长衫并小装。风来齐摆动，影上短墙黄。
→ 排列+日影计时，视觉收尾。

《久别重逢》相逢衣上味，不与旧时同。此味何时换，中间隔几冬。
→ 以气味当时间刻度，空白计量。

《久别重逢》人还隔半里，早认旧时形。走近方观面，相逢未唤名。
→ 身体记忆顺序（先认形→后观面→终未唤名）；省略即是内容。
