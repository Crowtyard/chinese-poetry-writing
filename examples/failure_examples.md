# examples/failure_examples.md —— 失败样本（真人裁决，标注归因等级）

来源：evidence/user_aesthetic_evidence.md。用途：REVISE/REJECT 的归因教学。
标注纪律：★=用户原话/明示；◇=我方归因（待更多样本验证），两者不得混用。

## 用户明示的失败（★）

- 鞋垫磨损被写成「脚印书」（UR-010Y）：用户原话转述——鞋垫磨损不等于必须写成「脚写的书」。
  归因：NO_FORCED_SYMBOLISM 违反（物被强行升华成象征）。
  → 教训：物本身有趣就让它保持为物；物证在场 ≠ 需要意义加冕。
- UR-000A 原版「明显像打油诗」（★）；UR-000B「构思不足」（★）；
  UR-000C「杯沿方案有发现，但表达仍弱」（★）；
  UR-000D「仍远离真正优秀的唐诗/好诗」（★）；UR-000E/UR-000F 系列 REVISE。
  ◇归因链：陈述句记账 / 结尾总结 / 照片无诗内在场证据（缺失非留白）/ 古风套语组装、信内零具体物 /
  旧纸墨痕语义重复、「温未沉」抽象情感总结 / 强发现但表达需省解释。

## 归因明确的失败（★+◇）

- UR-010X（鞋口朝天版）BOTH REJECT 之一：口语白描、构思单薄（◇）。
  → 教训：白描=安全是伪规则；语言层干净不是合格证。
- UR-006《下班》X REVISE / UR-008《未寄出的信》X REVISE：用户裁决 REVISE 未给理由（★裁决）。
  ◇观察（不归因）：UR-006X 顶针+「全看楼层数」书面结构、「各层各自分」偏解释；
  UR-008X 划痕物证成立但表达层或未达。→ 教训：原因未明时不许编造归因（NEEDS_HUMAN）。

## 模式叠加样本（◇ 自造教学样本，非用户裁决）

孤灯照影夜漫漫… → 情绪直说+漂亮词+凑韵+套语拼贴。
独倚高楼望故乡… → 伪古雅+古风套语+无物理来源的装饰意象+总结结尾。
夜深医院走廊凉… → 散文导语+标签化+抽象主题词+古典滤镜强加现代场景。
旧信重翻泪满襟… → 情绪直说+凑典+套语全栈+信内零具体物。

## 运行时教训（压缩版）

1. 修复从「找到不可替换细节」开始，不是从换词开始。
2. 批评须落句；说不出改哪里 = 批评没到位。
3. 无用户原话支撑的归因一律标 ◇ 或 NEEDS_HUMAN，禁止冒充事实。
4. 被 REVISE/REJECT 后重写时，先保诗眼与关系，再动语言（见 protocols/revise.md）。
