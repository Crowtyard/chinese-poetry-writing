# references/relational_imagery.md —— 关系意象（运行时精炼）

来源：research/relational_imagery.md。核心转向：不再问「意象俗不俗」，问「意象之间发生了什么」。

## 删除测试（对任意两意象 A、B）

1. 删 A——B 的意义变不变？不变 → A 装饰。
2. 删 B——A 的意义变不变？不变 → B 装饰。
3. 互相删除都无损 → 并列陈列，诗没在它们之间做功。

## RELATIONAL_IMAGE_SCORE（0-3，诊断工具不是及格线）

- 0 并列装饰：删任一，另一侧无损（「疏帘半卷雨如烟」）。
- 1 单向服务：A 只是 B 的背景/定语（灯白只是红的反衬）。
- 2 双向改变：删任一方另一方受损（「江碧鸟逾白」——互作比较基准与可见度量）。
- 3 关系即主题：意象组合本身就是发现（「秦时明月汉时关」；「却话巴山夜雨时」）。

纪律：全诗核心至少需要一个 ≥2 级关系或一条动作链；0-1 级只允许转场/收束句。

## 关系类型谱（供 compose 起手、critique 命名）

度量关系（A 使 B 可测）／因果反向（树不是被风推倒，是被自己的倾斜推倒）
／时间折叠（两个时间点在一个物上对折）／空间失配（A 的空间逻辑在 B 处失效）
／身份投射（物承担人的社会身份）／替代在场（人缺席时物执行人的功能）
／磨损考古（使用痕迹=关系史）。

## IRREPLACEABLE_FACT（不可替换事实）

= 一个只能属于「这一首诗的对象/时间/人物」的事实。三问：
- 为什么是这一封信？（不是任何旧信）
- 为什么是今天？（不是任何一次翻旧物）
- 为什么是这个人？（不是任何一位写信人）

细节三级：泛细节（旧信纸/划痕/灯，任何同题可用）→ 具体细节（+限定，可移植）
→ IRREPLACEABLE_FACT（自带身份：邮戳某城某年/一个错字/只有两人懂的称呼）。

关键规则：**最终诗不一定解释它（可留白），但创作者写之前必须先知道它。**
诗人不知道「这一封」是什么而写出的《旧信》，语言再干净也是类型诗。

反移植测试：把全部物象平移到相邻题材（旧信→旧照片/旧病历），诗意主体无损 → 无 2 级事实。

## 非意象关系（防模型盲区）

绝句的关系不一定在意象对上：
- 动作-反应链（《静夜思》举头→低头）
- 声音-空间（「人语响」→空山）
- 判断-物（「江流石不转」）

此时 RELATIONAL_IMAGE_SCORE 标 N/A，改用：**删去动作/声音/判断后，诗还剩什么**。
