# 创作前选择韵律体系

## 三个独立选择

1. 体裁：现代自由诗、五绝/七绝、五律/七律，或指定词牌。
2. 韵书：现代普通话可选中华新韵十四韵/十八韵；传统近体诗通常用平水韵；传统填词通常用词林正韵。
3. 词谱变体：填词时先查具体词牌和变体，再构思句式。词牌规定句式与声律，韵书规定字的声韵归属。

用户已指定的条件直接采用，不重复询问。未指定韵书的五绝/七绝保留现有现代新韵十八韵默认，
交付时说明是现代简化规则；不能称为平水韵或严格传统合律。
用户明确要求传统规则，或要求鉴赏古人作品时，不套用现代声调规则。
填词未指定韵书时默认词林正韵，先查词谱；有唯一适合目标体裁的变体时选用并注明，
有实质不同且无法从要求推定时才简短询问。不得为通过检查而暗换规则。

自由诗不套绝句扫描；其节奏与审美仍须自查，不伪造格律 PASS。

## 外部验律调度

所有脚本命令在姊妹项目 `chinese-poetry-prosody` 根目录运行；使用实际检出路径，
不假定某个用户的个人安装目录存在。Linux/macOS 使用 `python3`。

| 目标 | 调用 | 结果边界 |
|---|---|---|
| 现代普通话五绝/七绝 | `python3 scripts/check_poem.py --poem '<正文>' --form jueju7 --rhyme-profile xinyun18`；五绝改为 `jueju5` | 现有现代简化检查；不是传统完整规则 |
| 查平水韵 | `python3 scripts/traditional_prosody.py --dict pingshui char 白` | 外部字表的声类、韵部候选 |
| 比较传统韵部 | `python3 scripts/traditional_prosody.py --dict pingshui rhyme 斜 家` | 候选交集，不认证整诗 |
| 查词牌/变体 | `python3 scripts/traditional_prosody.py --dict cilin cipai 如梦令` | 先读谱再填词；不同词牌的变体名不同 |
| 词稿外部复核 | `python3 scripts/traditional_prosody.py --dict cilin --json check-ci --ci-pai 如梦令 --variant 定格 --poem '<正文>'` | 始终 WARN / EXTERNAL_REVIEW_REQUIRED，不转换为合律 PASS |

传统后端是可选、独立安装的程序。安装与完整命令见姊妹项目
`references/traditional_backend.md`。缺后端时如实报告未完成传统验律，仍可继续构思、成诗、
审美批评；不得把现代检查当替代，也不让 LLM 自行猜判传统韵部或平仄。
目前仍未提供传统律诗等体裁的全面整诗检查；支持创作不代表程序已经支持对应验收。

## 如何读外部结果

- 外部查询 exit 0 仅表示命令完成。上游匹配命令即使提示不匹配，也可能 exit 0。
- 字表缺字不能直接判作者用错字；多候选不能凭“能过谱”自动锁定语义读音。
- 匹配分数不是审美评分；分数 1 也不是完整传统格律认证。
- 词谱变体、分句、用韵、古今音不同都可能影响结果。遇到经典作品与工具矛盾，先核对资料，
  不擅自改原诗，也不将其作为失败范例写进教学资产。
- 对外明确区分“现代简化检查 PASS”“外部候选匹配/待复核”“未检查”。

## 用知识支持写作

先找到诗要表达的处境与关系，再选择韵律和可用表达。选定规则后可查询韵部候选，
帮助寻找自然的句尾；不能先定韵脚词，再编造事实或牺牲正常句法。
传统用典、意象、诗人风格可作参考材料，但不因选了古体形式就强塞古人名字或固定情绪。
审美修改与格律修改仍分开记录；待复核的外部提示不自动成为必改项。

参考学习对象：[wb14123/rhyme-checker](https://github.com/wb14123/rhyme-checker)。
采用其独立查字、查谱、匹配的工作方式，由姊妹项目通过进程调用。
本项目不复制其代码、韵书或词谱数据。
