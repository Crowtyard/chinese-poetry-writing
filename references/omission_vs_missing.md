# references/omission_vs_missing.md —— 留白 vs 信息缺失（运行时精炼）

来源：research/omission_vs_missing.md。

## 定义

- OMISSION（留白）= 读者能从**已有证据**推出未写内容（证据链完整，只是不说结论）。
- MISSING_INFORMATION（信息缺失）= 作者自己也没建立关系/给证据，只是没说清楚（推断无锚点）。

一句话：**留白省略的是结论；缺失省略的是前提。**

## 三问判定

1. 被省略的 X，诗中是否有 ≥1 处证据指向它？（无 → MISSING）
2. 补出 X 后，读者被「告知」还是被「照亮」？（告知 → 本应留白；照亮 → 真发现）
3. 删掉 X / 不解释 X，画面是否仍自洽？（不自洽 → MISSING）

## 速查表

| 信号 | OMISSION | MISSING |
|---|---|---|
| 推断锚点 | ≥1 个物理/动作证据 | 无锚点，全靠修辞词 |
| 补出 X 后 | 照亮 | 告知 |
| 删 X 后画面 | 仍自洽（只是更少） | 不自洽（变谜语） |
| 危险信号词 | —（证据在物与动作里） | 当年/似/温/空落落/陪… |
| 作者状态 | 知道但不说 | 不知道/没想清楚 |

## 经典锚点示例（留白=证据在物）

柴门闻犬吠→风雪夜归人（犬吠=「来人了」的物理证据）。
却下水晶帘，玲珑望秋月（下帘不想看 × 望月忍不住看，矛盾动作互证）。
临行密密缝→意恐迟迟归（缝的密度=担心的程度）。
他把伞往左偏，右肩淋湿了（护谁不言自明）。
整层楼先灭别人的灯，最后才轮到我（灭灯顺序=最后一个走）。

## 对 compose / critique 的指令

草稿出现「需要读者脑补作者脑内设定」的句子 → 先问：能否在诗内加一个物理证据
（动作/痕迹/声音）让推断成立？加不上 → 关系未建立，回 DISCOVERY 重做，**不用修辞掩盖**。
Critic 用三问定位：指「缺失」时必须指出哪个推断无锚点，不许只说「留白不足」。
