# references/poetic_discovery.md —— 诗性发现（运行时精炼）

来源：research/poetic_discovery.md。总纲：**RELATION_OVER_VOCABULARY——诗性来自关系，不是来自词汇。**

## 定义

POETIC_DISCOVERY = 在读者熟悉的事实中指出一个「此前未被说出、一经说出便无法忽视」的关系。
- 对象是关系（两物/动作/时间之间的连接），不是形容词；
- 来自事实内部（作者没发明事实，只重新安排注意），不是外部比喻；
- 说出后读者觉得「原来如此，我早该看见」；
- 绑定该事实，无法平移。

## 与近邻概念的边界（自查用）

| 概念 | 区别 | 验证 |
|---|---|---|
| 巧思 | 修辞姿态（拟人当发现） | 去掉修辞外衣还有没有事实内核 |
| 比喻 | 把 A 说成 B | 发现指出 A 与 B 在事实内部的结构连接，可不用比喻词 |
| 观察 | 看到 X | 发现=看到 X 与 Y 之间那条线 |

## 生产流程

FACT（可验证事实）→ OBSERVATION（拆成物/动作/光线/声音/空间/时间清单，不评价）
→ DISCOVERY（找关系空缺）→ POSSIBLE_RELATION（写成陈述：A 使 B 怎样 / A 与 B 互测 / A 消失后 B 暴露…）
→ 验证：能否平移？能 → 不是发现（是格言）。

## 起手方向（不是穷举）

反方向（灯熄了，夜的重量才落下来）／反尺度（整栋楼的灯与一个开关）
／反因果（不是人找灯，是灯等人）／时间的痕迹（旧物上叠两次事件）
／身体的证据（摘工牌后衬衫上没晒到的颜色）／声音的在场（无人时某声反而显出来）
／物的记忆（旧物上有手的形状）／消失后的剩余（人走后桌上留下什么形状的空）

## 普通词好诗的机制（背诵级示例）

床前明月光——名词并置，光路由远及近抵达身体坐标（床不可换窗）。
江清月近人——清→近因果，「近」是被制造的事实，一字驱动两物。
返景入深林——光的回头：撤退前最后一次深入（反常识方向）。
孤舟蓑笠翁——递减度量链：千山→孤舟→蓑笠翁，孤独由度量造成。
欲穷千里目——身体动词重定义欲望（穷=走完一千里路的目光）。
夜来风雨声——听觉得知、视觉缺席；落花是听出来的结论。

共同结构：普通词 × 非常关系。词没有升格，关系升格了。

## 运行时用途

- compose：FACT 之后必须先找出真 DISCOVERY 再动笔（≥3 个，关系类型真不同）。
- critique：缺发现的作品再干净也只是「正确而无用」——检查点：全诗最强关系是什么？能平移吗？
