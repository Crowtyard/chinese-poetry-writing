# protocols/critique.md —— 批评协议（v0.1-beta / STEP 2）

来源：research/bad_poetry_patterns.md、research/relational_imagery.md、research/omission_vs_missing.md、research/endings_taxonomy.md、evidence/user_aesthetic_evidence.md（提炼）。
用途：交付前自查（创作后必须过此层）；也用于评审他人诗。不做审美之外的事：声韵判定归 chinese-poetry-prosody。

## 优先检查六项（按序，全部要落到"哪一句/哪个词/为什么"）

1. EVIDENCE（物证在场）
   诗的核心判断/情绪是否有可感知的物证支撑？删除证据后诗是否坍塌？
   坍塌前先救证据：是缺失证据，还是只是没说结论（见留白检查）。

2. RELATION（关系做功）
   最强关系对是谁/谁？删 A 后 B 变不变？删 B 后 A 变不变？
   删除测试只是工具，不是判决：删掉一端后另一端仍能独立成立，不能单独证明原关系薄弱——
   单独成立完全合法，句法独立 ≠ 诗内独立（`REMAINING_LINE_STILL_WORKS != ORIGINAL_RELATION_DID_NOT_WORK`）。
   删一端，先看什么随之改变，再问原组合的顺序／动作／对照／递进／呼应是否因此消失或减弱；
   消失或减弱 → 关系可能真实做功；连这些都不变，「可删」才可作辅助证据。
   反向同守：`MECHANISM_PRESENT != MECHANISM_WORKING`——名义上的顺序／递进／对照出现时，
   仍要看它是否真的改变了整首诗的组织（阅读落点／注意力走位／意义推进），不因表面形式放行。
   全诗核心是否至少一个互相定义的关系（≥2 级）或一条动作-反应链？顺序、递进、对照、呼应型同样计入。
   两个以上意象互不影响 → 并列陈列，指出是装饰性意象。

3. NATURALNESS（自然度）
   逐句朗读：是现代白话能真实说出的句子，还是散文记账切行/压缩翻译腔/伪文言倒装？
   注意：白话白描不是散文压缩；句内有可感知的物与力即自然。

4. EXPLANATION（解释度）
   是否给事件起名字代替呈现（解释事件）？是否直接交付情绪结论（解释感情）？
   末句能否翻译成一句主题句（结尾总结主题）？能 → 该结尾功能未生效。

5. TECHNIQUE_VISIBILITY（技巧可见度）
   拟人、悬顿、反问、顶针等技巧是否比观察本身更显眼？技巧是否在替物证做工作？

6. IRREPLACEABILITY（不可替换性）
   反移植测试：核心细节平移相邻题材，诗意损失大/中/小？小 → 类型诗。

## 高层提醒 · AFFECTIVE NECESSITY（一句话提醒，不是第七项、不是分类器）

六项之外只多问一句：

> 除了检查事实、物象是否具体，还要问：这些事实、物象和动作为什么被选进同一首诗？
> 如果它们只是因为属于同一个题目／场景而被并列在一起，可能仍只是景物陈列。

- `SCENE_COHERENCE != AFFECTIVE_NECESSITY`：属于同一场景，不等于已经形成有意义的诗歌组织。
- `AFFECTIVE NECESSITY != EMOTIONAL_INTENSITY`：克制、安静、少情绪词**不等于**缺少思想感情；
  不得因此要求感叹、显式情绪词或增强煽情。
- 若提醒发现陈列迹象，不另立分类器、不新增标签：直接回到既有机制
  （`DECORATIVE_IMAGE`／`RELATION_TOO_THIN`／`FACT_REPORTING` 或其他最准确的现有诊断），照常走三档判决。

## 补查（发现上两项问题后必查）

- 留白 vs 缺失三问：省略的 X 在诗内有无 ≥1 处证据指向？补出 X 读者是被"告知"还是被"照亮"？
  删掉 X 画面是否仍自洽？无锚点 → 信息缺失，不是留白。
- 「的」六问（同 compose）：出现「的」不自动扣分；通过六问的「的」不构成问题。
- 结尾功能核对：末句声称的功能（定格/拉远/拉长/反转/物存/悬置/回响）所要求的证据在不在诗里。
- 收束性结尾若完成前文已建立的动作/物理关系链 → 有效（ENDING_RESOLUTION），不是总结。

## 判决三档（必须显式落一档）

调用 Critic **不等于**必须找出问题。三档都是合法结论。依据：Critic FP Control 6/6 无过度诊断、
0 例装饰性建议；同时 1 例过度解释记录在案（见下方护栏）。

- `MATERIAL_PROBLEM` —— 存在足以要求修改的实质问题。必须落到句：哪一句／根因／修改方向。
- `LOCAL_RISK` —— 局部风险：该处有可指认的风险，但**不足以判定作品失败**。
  `LOCAL_RISK != POEM_FAILURE`；允许与 KEEP 并存，只登记不强制修改。
- `NO_MATERIAL_PROBLEM` —— 无实质问题。表面风险可能被触发，但在上下文中成立；
  必须说明**为什么成立**（它做了什么工作），不要求修改。

禁止：为了显得尽责而制造问题；给已判无实质问题的文本追加「可以更凝练／更雅／更生动」式装饰建议
（COSMETIC_OVERCRITIQUE = 禁止）。

孤立片段（单句／残句／不完整节选）判档：

- 片段模式只判断片段内部实际可见的问题：缺少整诗 premise、上下文锚点、全诗推进、收束或更大结构，
  属于 `UNKNOWN_CONTEXT`，不能单独据此升级为 `MATERIAL_PROBLEM`／`REVISE`／`REJECT`
  （`MISSING_WHOLE_POEM_CONTEXT != LOCAL_DEFECT`）。
- 片段内要判 `MATERIAL_PROBLEM`／`REVISE`／`REJECT`，必须指出一个在片段内部即可成立的实质缺陷
  （明显语义断裂／关系自相矛盾／为韵压坏语言／局部重复真的没有功能／本片段本身就是无关系的事实并列）；
  「放进整首诗可能不够」「缺少更大的锚点」「没有全诗推进」「构思还不够完整」不是升级理由。
- 句内关系自足（句法本身在执行关系，如一个动词带两个对象）→ 可判 `NO_MATERIAL_PROBLEM`，说明句内依据。
- 所缺锚点不在本片段内、且句内看不出关系工作 → 登记 `LOCAL_RISK`（不判必改，须回到完整上下文）。
- 不得仅因「没有上下文」把好句判成问题（历史 FP 控制中，孤立好句的正确处理就是不判必改）。

与既有判决词的关系：`MATERIAL_PROBLEM` ⊃ REVISE / REJECT；
`LOCAL_RISK`／`NO_MATERIAL_PROBLEM` ⊂ KEEP（必要时附 NEEDS_HUMAN）。

## INTERPRETIVE_OVERREACH_GUARD（过度解释护栏）

原则：**DIAGNOSE WHAT THE TEXT DOES** —— Critic 可以解释诗内已经存在的语言关系如何工作，
但不得为了显得深刻，把可能的心理故事、隐藏主题或象征意义说成作品已经确定表达的内容。

- 允许：指出文本已经写出的动作递进、次序、悬置与对照，并说明其诗内证据。
- 不得擅自断言：文本未写出的动机、未点明的心理原因，或把某种解读说成作者已经确定表达的意思
  ——那是替诗补出一层文本没有的解释（真人判定：过度解释）。
- 只解释文本已经做出来的关系，不把可能的心理故事说成确定主题。
- 纪律：机制命名只能停在诊断层（说明风险为何成立／不成立），不得漂移成阐释替身。

## 禁止的反射动作（六不判）

- 看见「的」→ 判差 ✗
- 看见结尾收束/完成动作 → 判总结 ✗
- 看见现代口语 → 判廉价 ✗
- 没有状态变化/动态链 → 扣分 ✗
- 句法不对称 → 扣分 ✗
- 看见古典词 → 判套话 ✗

另有两条历史教训：
- 白描 ≠ 安全：构思单薄的白描照样 REJECT（口语层干净不是合格证）。
- 模式是定位工具，不是关键词死刑：同一词在此诗可活、在彼诗可死，判据是它是否建立了本诗独有的关系。

## 判决格式（先写三档，再写判决词）

- KEEP：过六项（可附非阻断观察）。
- REVISE：至少一处"句 + 根因 + 修改方向"；修复应从补证据/换关系入手，不是先换词。
- REJECT：指明 1-3 个根因（构思单薄 / 无不可替换事实 / 强行象征 / 解释收尾…），定位到句。
- 有疑问标 NEEDS_HUMAN：本协议不硬判（历史上 Critic 曾误伤口语佳句、放过类型诗；FP/FN 存在，宁可留白）。
- 每份诊断**先显式写出三档中的哪一档**，再落上述判决词。
- 诊断内部须自洽（`DIAGNOSIS_INTERNAL_CONSISTENCY = REQUIRED`）：已认定某个局部关系正在实际做功，
  就不得又以「没有关系／无关系推进」作为升级理由——除非明确指出这是另一层、另一位置的独立问题。

## 使用纪律

- 单一辅助信号（如物象可替换）不能单独推出 `RELATION_TOO_THIN`／`DECORATIVE_IMAGE`／`FACT_REPORTING`，
  也不能单独构成「需要修改」；它只用于校验诊断，判据是关系在文本里是否实际做功（见 RELATION）。
- `PLAIN_PHYSICAL_FACT != FACT_REPORTING_FAILURE`：语言朴素、动作具体、描述物理事实，不等于 `FACT_REPORTING`。
  文本内部的动作—结果、对照、顺序等关系已实际做功时，不能仅因「它在写事实」升级为 `MATERIAL_PROBLEM`／
  `REVISE`／`REJECT`；仍要判该标签，须补出文本内额外可见的「只报告而未形成关系」的证据。
- 诊断工具（关系分级、模式库）不是及格线：动作链诗可对意象对判 N/A，以"删去动作/声音/判断后还剩什么"替代。
- 本层只判断审美与结构；Prosody PASS ≠ 审美合格，本层结论独立于验律结果。
