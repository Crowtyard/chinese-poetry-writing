# protocols/critique.md —— 批评协议（v0.1-beta / STEP 2）

来源：research/bad_poetry_patterns.md、research/relational_imagery.md、research/omission_vs_missing.md、research/endings_taxonomy.md、evidence/user_aesthetic_evidence.md（提炼）。
用途：交付前自查（创作后必须过此层）；也用于评审他人诗。不做审美之外的事：声韵判定归 chinese-poetry-prosody。

## 优先检查六项（按序，全部要落到"哪一句/哪个词/为什么"）

1. EVIDENCE（物证在场）
   诗的核心判断/情绪是否有可感知的物证支撑？删除证据后诗是否坍塌？
   坍塌前先救证据：是缺失证据，还是只是没说结论（见留白检查）。

2. RELATION（关系做功）
   最强关系对是谁/谁？删 A 后 B 变不变？删 B 后 A 变不变？
   全诗核心是否至少一个互相定义的关系（≥2 级）或一条动作-反应链？
   两个以上意象互不影响 → 并列陈列，指出是装饰性意象。

3. NATURALNESS（自然度）
   逐句朗读：是现代白话能真实说出的句子，还是散文记账切行/压缩翻译腔/伪文言倒装？
   注意：白话白描不是散文压缩；句内有可感知的物与力即自然。

4. EXPLANATION（解释度）
   是否给事件起名字代替呈现（解释事件）？是否直接交付情绪结论（解释感情）？
   末句能否翻译成一句主题句（结尾总结主题）？能 → 该结尾功能未生效。

5. TECHNIQUE_VISIBILITY（技巧可见度）
   拟人、悬顿、反问、顶针等技巧是否比观察本身更显眼？技巧是否在替物证做工作？

6. IRREPLACEABILITY（不可替换性）
   反移植测试：核心细节平移相邻题材，诗意损失大/中/小？小 → 类型诗。

## 补查（发现上两项问题后必查）

- 留白 vs 缺失三问：省略的 X 在诗内有无 ≥1 处证据指向？补出 X 读者是被"告知"还是被"照亮"？
  删掉 X 画面是否仍自洽？无锚点 → 信息缺失，不是留白。
- 「的」六问（同 compose）：出现「的」不自动扣分；通过六问的「的」不构成问题。
- 结尾功能核对：末句声称的功能（定格/拉远/拉长/反转/物存/悬置/回响）所要求的证据在不在诗里。
- 收束性结尾若完成前文已建立的动作/物理关系链 → 有效（ENDING_RESOLUTION），不是总结。

## 禁止的反射动作（六不判）

- 看见「的」→ 判差 ✗
- 看见结尾收束/完成动作 → 判总结 ✗
- 看见现代口语 → 判廉价 ✗
- 没有状态变化/动态链 → 扣分 ✗
- 句法不对称 → 扣分 ✗
- 看见古典词 → 判套话 ✗

另有两条历史教训：
- 白描 ≠ 安全：构思单薄的白描照样 REJECT（口语层干净不是合格证）。
- 模式是定位工具，不是关键词死刑：同一词在此诗可活、在彼诗可死，判据是它是否建立了本诗独有的关系。

## 判决格式

- KEEP：过六项（可附非阻断观察）。
- REVISE：至少一处"句 + 根因 + 修改方向"；修复应从补证据/换关系入手，不是先换词。
- REJECT：指明 1-3 个根因（构思单薄 / 无不可替换事实 / 强行象征 / 解释收尾…），定位到句。
- 有疑问标 NEEDS_HUMAN：本协议不硬判（历史上 Critic 曾误伤口语佳句、放过类型诗；FP/FN 存在，宁可留白）。

## 使用纪律

- 诊断工具（关系分级、模式库）不是及格线：动作链诗可对意象对判 N/A，以"删去动作/声音/判断后还剩什么"替代。
- 本层只判断审美与结构；Prosody PASS ≠ 审美合格，本层结论独立于验律结果。
