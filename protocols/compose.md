# protocols/compose.md —— 创作协议（v0.1-beta / STEP 2）

来源：research/poetic_discovery.md、research/relational_imagery.md、research/omission_vs_missing.md、research/endings_taxonomy.md、evidence/user_aesthetic_evidence.md（提炼，不复制全文）。
职责边界：Persona 提供题目、人格、经历、视角、声音；本协议提供方法；验律归 chinese-poetry-prosody。

## 主流程

FACT → IRREPLACEABLE_FACT → DISCOVERY（≥3）→ RELATION（选定）→ 2-3 CONCEPTS → DRAFT

## 输入契约：AFFECTIVE INTENT（思想感情方向）

起草前必须已经有一句内部写作方向（三问见 `protocols/orchestration.md` 步骤 0.5）：
本诗准备承载什么感受或认识，以及哪些事实、动作、关系能承载它。
没有它就没有 FACT 的取舍标准，写出来的就是「与题目有关的景物陈列」。

- 它影响的是：注意什么 / 选什么 / 舍什么 / 关系怎么组织 / 诗在哪里停；
  **不是**把「悲伤／孤独／思念／惆怅」等词写进诗里（`AFFECTIVE_INTENT != EMOTION_WORDS`）。
- 目标 `READER_FEELS_IT_BEFORE_THE_POEM_EXPLAINS_IT`：让感情从关系、动作、物象、语气、节奏、
  留白、结尾位置里出现，不由解释句交付。
- 下列步骤（FACT／DISCOVERY／RELATION／CONCEPT）**优先选择能承载该方向的事实与关系**；
  具体但与情感无关的事实可以舍弃。
- 反向禁止：不得为了迎合情感方向歪曲或添加事实，也不得添补输入不支持的重大事实
  （`FORCED_SIGNIFICANCE_GUARD`）。
- 情感很轻是合法的：方向可以只是一点语气或一点不舍，不必强行加重；找不到自然方向时按失败处理
  （换题或如实报告），不硬贴模板（`AFFECTIVE_TEMPLATE_GUARD`）。

### 1. FACT（事实清单）

只列可验证事实：人物、动作、物件、声音、光线、空间、时间变化。
不评价、不抒情、不解释。清单里没有的物，诗里不得凭空出现。

### 2. IRREPLACEABLE_FACT（不可替换事实）

三问，至少一问必须答得上：
- 为什么偏偏是这个物件/这封信？（换一个同类，诗意是否塌）
- 为什么偏偏是今天/这个时辰？（换一天是否成立）
- 为什么偏偏是这个人？（换任何人是否成立）

反移植测试：把核心细节平移到相邻题材，诗意主体若无损 → 没有不可替换事实，回 FACT 重找。
纪律：写之前必须先知道"这一件"是什么；诗中可以留白不解释它，但创作者不能不知道。
找不到 → 不硬写，换观察角度或换题。

### 3. DISCOVERY（诗性发现，≥3 个真不同）

DISCOVERY = 在熟悉事实中指出一个"此前未被说出、一经说出便无法忽视"的关系。
它必须是关系（两个物/动作/时间之间的连接），不是形容词，不是情绪，不是道理。

起手方向（不是穷举）：
- 反方向：灯熄了，夜的重量才落下来
- 反尺度：整栋楼的灯与一个开关
- 反因果：不是人找灯，是灯等人
- 时间的痕迹：一个物上叠着两次事件
- 身体的证据：摘掉工牌后衬衫上一块没晒到的颜色
- 声音的在场：无人时某声反而显出来
- 物的记忆：旧物上有手的形状
- 消失后的剩余：人走后留下什么形状的空

验收：
- 平移测试：挪到邻题还成立 → 是格言，不是发现。
- 巧思测试：去掉修辞外衣还有没有事实内核 → 无 = 巧思，退回。
- 三个 DISCOVERY 必须关系类型真不同（只换词面不算）。

### 4. RELATION（选定一条真正做功的关系）

至少一个物象对满足：删 A，B 的意义变；删 B，A 的意义变（互相定义，≥2 级），
或全诗靠一条动作-反应链做功（如《静夜思》举头→低头）。
0-1 级关系只允许用于转场/收束句，不能当全诗核心。
关系类型参考：度量关系 / 因果反向 / 时间折叠 / 空间失配 / 替代在场 / 磨损考古 / 动作-反应链。

### 5. CONCEPTS（2-3 个完整不同构思）

每个 CONCEPT = 一个完整可执行的短诗构思（诗眼 + 关系 + 大致画面走向），彼此真正不同。
选 1 个主构思进草稿；若首个草稿失败，换 CONCEPT 而非在同构思上硬磨。

### 6. DRAFT（语言层纪律）

- 实词优先：名词、动词、具体形容词。抽象词不得做主语/谓语；只允许做"被具体物执行的宾语"。
- 意合优先：能名词并置就不加连接；少用散文连接与解释性虚词。
- 「的」是 HIGH_COST_FUNCTION_WORD，不是禁词。每次使用过六问：
  ① 删除后是否成立/语义是否受损；② 能否名词并置；③ 能否改动词关系；
  ④ 能否调整语序；⑤ 是否只是普通所属/说明性定语；⑥ 朗读节奏是否站得住。
  承担口语声口、完成事件名物化（她削的果/孩子画的线）、指别、必要节奏时允许保留。
- 白话 ≠ 低级：可以白、可以直、可以口语，只要节奏成立、用词准确、关系清楚。
- 朴素 ≠ 漂亮词堆砌：每个意象必须对关系做功；拿不准就做删除测试。
- 反古风滤镜：不为"像古诗"用现代人不知所指的词（伪古雅判据：现代读者知道它指什么吗 /
  它比现代词更准吗，两者皆否即伪古雅）。
- 第四句落笔前先选结尾功能（IMAGE_LOCK / SPACE_OPEN / TIME_OPEN / SEMANTIC_REVERSAL /
  OBJECT_REMAINS / UNANSWERED_ACTION / ECHO，见 references/endings.md）；
  收束可以完成前文已建立的动作/物理链（ENDING_RESOLUTION 是有效结尾）。
- 不为押韵选词：语义先到，韵白捡；拿不准的韵与平仄留给 prosody 复核，不在此层猜。
- 不被下列伪规则绑架（见用户证据"明确禁止的推导"）：
  第三句不必强转（可推进/加深/对照/停顿）；不必全部短句；不必全部对称；
  不必全部无「的」；不必有状态变化（静态物证+关系在场即可成立）。

## 失败处理

- 找不到 IRREPLACEABLE_FACT 或真 DISCOVERY → 不硬造，回 FACT 或换题。
- 构思 ≤3 轮仍无自然成稿 → 如实报告 UNRESOLVED，不降格硬交。
