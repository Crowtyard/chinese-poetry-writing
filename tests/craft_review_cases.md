## 已试运行的素材案例

输入：带病听课，头昏、想睡但不能睡；坚持不住低头眯了一会儿，梦见朋友发消息，用意念回复她。
体裁：七绝；韵律沿用现代普通话新韵十八韵；没有新增传统合律声明。

旧稿（本会话此前交付的稿件，不是重新运行旧版生成的对照）：

> 带病听课眼难睁，才一低头梦已生。
> 恍惚之间来短信，一字一句意中成。

关键细节复核：病中课堂和梦境在；第三句没有明确来信者是朋友，末句更像心中成句，
没有清楚保留“回复对方”。这是对本输入的具体语义保留问题，不是因为语言白话或结尾没有画面。

按新方法试拟的候选：

> 病中听课眼难睁，才把头低梦已生。
> 忽见友人传短信，心中回罢手犹停。

内部写作方向：保留疲惫中的醒梦错位和意识已经完成回复的轻微诙谐，不扩大为深情或离别。
候选保留朋友、梦境与回复的指向；“手犹停”是对意念回复的表现性推演，
原输入未明说手的状态，不能把它记录成用户确切经历。

Critic 自检：`LOCAL_RISK / KEEP（待真人反馈）`。
末句形成意识回复与手上动作的对照；第二句“才把头低”仍有语序刻意的风险，
本次不将候选登记为满意定稿。没有凭形式通过或补回信息就声称诗味更好。
实质修改的 POETIC_EYE_PRESERVED / NATURAL_SYNTAX_PRESERVED 自检为 TRUE；
后者只表示句法可理解，不消除上述语气风险，仍待用户裁决。

程序验证（在姊妹项目根目录）：

```bash
python3 scripts/check_poem.py \
  --poem '病中听课眼难睁，才把头低梦已生。忽见友人传短信，心中回罢手犹停。' \
  --form jueju7 --rhyme-profile xinyun18 --json
```

本次实际结果：exit 0，verdict=PASS，七字四句，issues 为空。
这只证明现代简化形式检查通过，不证明传统格律或审美验收通过。

## 已进行的边界案例复核

以下是对规则行为的定性自检，不给诗句打分，不构造自动通过计数。

| 案例 | 本次复核结论 |
|---|---|
| “星垂平野阔，月涌大江流”（杜甫《旅夜书怀》）同时有星与月 | 不因两个意象共存判错；仍可考察其空间与动作关系，不套“月星抢戏”禁令 |
| “举头望明月，低头思故乡”（李白《静夜思》）直接写“思” | 不强行改为纯画面；明确情感词与动作共同构成表达，不能仅因直抒判必改 |
| 将“看见朋友”替换成“寻找朋友” | 候选增加了主动寻找的意图；同素材推敲时不能只因动词更有力就替换 |
| 将梦中来信改成“醒来查手机看到未读消息” | 新增现实事件，关键边界改变；作为此用户经历的改写应撤回，不靠漂亮词掩盖 |
| 为普通朋友来信自动加“绝弦” | 增加知音亡故的意味，输入无依据；保留不用典版本，不把典故数量当进步 |
| 七言诗中出现“短信” | 不因词语现代而判差；是否自然、准确仍看整句，不强换成真实纸信 |
| 梦中通过意念回复 | 已有梦境语境，不按现实通信方式判不可能；也不借此推断用户现实中已发送消息 |
