# 修订重放、独立对照与人工盲评

`cases.json` 包含 5 个固定修订对照（历史报告、构造反例、局部替换、KEEP 控制），
以及 2 个未用于修订示范的新题。记录各自来源，不能统称为新旧版独立生成。
R03 特意保留原上下文用于检验指定句的改动；全文仍有未修事实，禁止作为最终交付稿。

运行重放与匿名包装（输出须为不存在的新目录）：

```bash
python3 tests/revision_eval/package_review.py --prosody ../chinese-poetry-prosody --output /tmp/poetry-review
```

实际执行每份整稿的现代检查，保留完整 JSON、argv 和退出码，绝不沿用旧 PASS；
`blind-review.md` 只含题面与匿名候选，技术结果、来源标签、映射放在 `private/`。
组织者只发盲评表给评阅者，回收后再揭示来源与技术结果。评分可以原稿更好、两者都差或相同。
事实保留、表达自然度、意象作用分别写依据；格律单列，不汇成“写作质量总分”。
